## ⚖️ 二、体用生克断法大则

- **体卦**：为主体、为我、为所求之主事，静而守位；
- **用卦**：为事端、为客、为外应时势，动而生变；
- **互卦**：事之中间过程、暗中隐伏之机理；
- **变卦**：事之终局、事态最终之落点。

| 生克格局 | 吉凶定断 | 现实事理映射 |
| :--- | :--- | :--- |
| **用生体** | 大吉，求之易得 | 得外力相助，贵人扶持，顺风顺水 |
| **体生用** | 耗泄，劳而少功 | 损己利人，付出巨大，心力交瘁 |
| **体克用** | 吉，克敌制胜 | 虽有阻力，但能掌控局势，胜券在握 |
| **用克体** | 凶，大受制约 | 遭外界压制打击，阻碍重重，败兆显露 |
| **体用比和** | 吉庆，谋为和谐 | 伙伴齐心，上下协力，安稳成就 |
