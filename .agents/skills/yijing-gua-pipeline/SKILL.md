# 易道工坊 · 六十四卦全息精研与自修课件工程化标准规范（Pipeline SOP）

> **使命目标**：将项目庞大的经典古籍与现代心智模型知识库，转化为**结构严密、通俗透彻、极具教学深度、大字宽屏排版**的现代自修大课。  
> **核心铁律**：  
> 1. **全盘覆盖，拒绝偷懒**：每一卦必须联动知识库 6 大源头（档案、朱熹本义、程颐易传、孔颖达正义、梅花易数、时位辩证），杜绝知识割裂。  
> 2. **引经据典，必附通译（绝对红线）**：严禁仅罗列生硬文言文经文！凡出现卦辞、彖传、大象传、各爻爻辞、小象传、文言传以及古籍引文，下方**必须紧跟通俗精准的【大白话通译】**（逐句拆解字面义、因果逻辑与深层引申义），彻底打破古文阅读门槛。  
> 3. **拒绝口水，深度教学**：杜绝“同学们好”等口水话，严禁直接堆砌生硬古文；必须由浅入深、逐词解构、讲透原理与历史案例。  
> 4. **离线处理，严禁爆上下文**：大模型严禁在提示词中一次性读入超长全库文本，严禁直接在单次回复中吐出几万字。所有抽取、清洗、合并、转换全部由本地独立 Python 脚本单向推进。

## 二、 工程化防御：彻底规避“上下文爆炸与 EOF 断连”架构

为什么此前大模型会频繁发生 `59s thought > EOF > connection reset`？  
原因在于：把大模型当成了“文件读写器和巨型文本流传输器”。当传输量达到几万字或并发读取大文件时，RPC 连接超时中断。

### 防御核心三原则（Zero-Context-Overflow）：
1. **大模型只控流程，不搬砖头**：大模型只生成和执行小脚本，不把原著全文打印到对话上下文。
2. **全流程本地脚本化（Script-Driven）**：
   * `Step 1 提取切片` ➔ Python 脚本写入 `data/slices/<id>_slice.json`；
   * `Step 2 分步汇编` ➔ Python 脚本分篇章追加写入 `data/<id>_全息知识精研汇编.md`（经文必须配通译）；
   * `Step 3 课件注入` ➔ Python 脚本精准正则切分并写入 `course_data.js`。
3. **终端轻量反馈**：终端命令仅输出 `SUCCESS: xxx bytes written`，回传上下文不超过 100 字符。

## 三、 标准全息大课“七大章节”结构规范

每一卦生成的 Markdown 汇编文档与最终课件，必须严格遵循以下统一篇章结构：

### 壹 · 经传宗本原典与白话通译档案（必附翻译）
* 卦象物理参数（卦体、二进制编码、卦德、五行）；
* 文王卦辞 + **【大白话通译】**；
* 孔子《彖传》 + **【大白话通译】（逐句对译，解构宇宙化育模型）**；
* 孔子《大象传》 + **【大白话通译】（解构天人合一法则）**；
* 周公六爻辞与孔子《小象传》 + **【大白话通译】（逐爻解构时位状态与行为指南）**；
* 用九/用六（乾坤专属） + **【大白话通译】**。

### 贰 · 先贤四大宗师宏观义理解构
* **程颐《伊川易传》**：天道与性情之辨、卦德闭环（如元亨利贞四阶段算法）；
* **朱熹《周易本义》**：占筮本义、卦象刚柔比例、象占审断前置条件；
* **孔颖达《周易正义》**：王弼注得意忘象、三才名理；
* **邵雍《河洛理数》**：四字心诀断语与总体气数研判。

### 叁 · 孔子《象传》与《文言传》全息心印精研
* 阐发大象传天道人道合一法则；
* 逐爻修养心法深度剖析（乾坤为文言传，其余卦为小象传与系辞传合参）。

### 肆 · 核心义理历史贯通（程颐钦定历史剧场）
* 将抽象的六爻演进，映射为**一个真实历史人物/经典事件的六个进阶节点**（如乾卦映射虞舜从草莽农夫到登临天子）；
* 消除学员记忆门槛，通过故事线串联时位演进。

### 伍 · 梅花易数万物全息类象与体用生克法
* 先天数、五行生克、空间方位、时序节气；
* 天象、地理场所、社会人物、性情心理、生物动物、器物财物、人体部位、疾病病理全息映射；
* 梅花易数体用生克（生体、克体、体克用、体生用、比和）实战审断法则。

### 陆 · 易理时位辩证法则深度映射
* 六爻“得位”与“失位”刚柔配比分析；
* 剖析“得中胜于得位”的中庸平衡智慧；
* 爻位间的同德相应或刚柔正应、乘承比应辨析。

### 柒 · 现代场景攻防映射、认知反思与费曼实战工坊
* **职场/个人发展 6 阶攻防路线图**：各爻现实战法与致命红线禁忌；
* **三大反常识心智反思**：深挖 3 个常人最易踏入的认知误区并给出底层解构；
* **费曼实战工坊**：提供具体实战困局挑战题（如商业扩张、合伙人冲突），给出 3 分钟标准答题逻辑要点。

## 四、 页面呈现与前端排版标准

1. **宽屏全幅自适应**：
   * 主视窗必须彻底铺满屏幕（`max-width: 100%`），严禁设置窄宽导致大屏两侧留白过大；
2. **清晰大字号阶梯**：
   * 基础正文：`16px ~ 16.5px`，行高 `1.85`；
   * 经典引言框（`.classic-quote`）：`16.5px`，深色底色配主题色左边框；
   * 小节标题（`.sub-sec-title`）：`20px` 黄金加粗；
   * 爻位小标题（`.yao-sub-title`）：`18.5px`，带有锚点 ID（`id="yao-card-初九"`）。
3. **竖向时位演进天梯**：
   * 严格遵循“自下而上”（初爻在底、上爻在顶）；
   * 支持一键点击梯级，平滑平移定位到对应爻的深入攻防剖析处。

## 五、 后续卦象质量自检红线清单（Checklist）

在交付任何一卦之前，必须自检以下 7 项红线，缺一不可：
- [ ] **1. 原典通译齐全**：卦辞、彖传、大象传、六爻辞、小象传、用九/用六下方，是否**全部配齐通俗精准的【大白话通译】**？

- [ ] **3. 历史剧场鲜活**：是否有程颐钦定的历史人物案例贯通六爻脉络？
- [ ] **4. 象数生克明确**：梅花易数五行生克与体用吉凶断法是否完整严密？
- [ ] **5. 时位得中辨析**：是否阐明了当位与失位、得中重于得位的辩证关系？
- [ ] **6. 现代攻防与费曼挑战**：职场 6 阶图、3 大反思、3 分钟费曼挑战题是否具备实战指导价值？
- [ ] **7. 排版视觉舒适**：是否为大字版（16.5px）、宽屏铺满、无小窄缝、天梯点击定位顺畅？
