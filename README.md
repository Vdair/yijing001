## ⚡ 为什么适合 AI 调用并节省资源？

1. **结构化标题锚点（Markdown Headers）**：  
   文档采用 `#`、`## 壹·`、`### 爻位【...】` 等标准 Markdown 标题，AI 可以通过语义分段瞬间定位具体章节，无需解析复杂嵌套的 JSON。
2. **微文件隔离（Micro-File）**：  
   单卦文件独立存在（平均仅 2.5KB，约 800~1200 Tokens）。AI 需要了解具体某一卦时，直接单篇读取，节省 90% 以上上下文开销。
3. **全局速查卡支持（Global Cheat Sheet）**：  
   在面对全局问题（例如“推荐三首适合处于低谷期阅读的卦”）时，AI 只需一次性载入 [64卦卦义与卦象速查卡.md](04_AI极速参考手册/64卦卦义与卦象速查卡.md)（仅 ~3000 Tokens），即可概览全局。
4. **零污染与零幻觉**：  
   爬虫残留广告与版权噪音已 100% 滤除，专业易学术语已在 [易学术语与基础概念辞典.md](04_AI极速参考手册/易学术语与基础概念辞典.md) 中规范定义。
