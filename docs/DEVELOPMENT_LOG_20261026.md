### 2. 导航系统致命 TypeError 深度排查与修复
- **排查痛点**：
  - 用户反馈“当前查阅后面的卦无法点击”，排查定位至第 35 卦（火地晋）及之后所有卦象点击无响应。
- **根因分析**：
  - 批量生成数据注入时，第 35~64 卦的 `lines` 字段被存储为 String 字符串（如 `"000101"`），而第 1~34 卦为数字 Array。
  - 在 [learn.html](file:///Users/a58/Desktop/易经知识库/learn.html) 构建“竖排六爻天梯”时直接调用 `lesson.lines.forEach()`，字符串调用触发 `Uncaught TypeError: lesson.lines.forEach is not a function`，导致 JS 引擎崩溃中断。
- **全链路修复与双重容错**：
  1. **数据层**：清洗 `course_data.js`，将 30 个卦象的 `lines` 字段完全规整为标准数字数组；
  2. **展现层**：在 `learn.html` 中引入防御性编程，对 `lines` 进行动态类型判断与安全数组转换；
  3. **交互层**：新增 `scrollIntoView` 智能聚焦机制，点击或切换任意卦象时，侧边栏目录自动平滑滚动并将当前卦置于可视区中央；
  4. **缓存层**：更新 `course_data.js?v=20261026_1715` 强版本号，杜绝开发与生产环境下的静态文件缓存干扰。
